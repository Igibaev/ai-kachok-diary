# Changelog

## 1.1.1 — любая нейросеть (2026-10-04)

### Продукт
- AI-слой прокси стал **провайдер-независимым**: чат AI-тренера и AI-повар работают на любой модели — Anthropic Claude (по умолчанию), OpenAI, Google Gemini, DeepSeek, OpenRouter, локальные модели через OpenAI-совместимый API (Ollama, vLLM). Выбор — одной переменной на прокси, без пересборки приложения; ключи по-прежнему только у клуба.
- Повар может работать на другой модели, чем чат (например, чат на Claude, фото еды на Gemini). Требование к модели повара: понимает изображения и отдаёт JSON; точность оценки по фото зависит от модели.

### Инженерия
- Прокси: слой `src/providers/` — интерфейс `AiProvider` (`generateText`, `generateJson<T>` с zod-схемой), реализации `anthropic.ts` (`@anthropic-ai/sdk`, как раньше) и `openaiCompatible.ts` (`fetch` на `/chat/completions` без SDK: `response_format: json_schema` с откатом на `json_object` + схема в промпте, валидация `safeParse` и один повтор, изображение как `image_url` data-URL, `AbortController`). Единый `ProviderError` (`auth` / `rate_limit` / `refused` / `bad_output` / `timeout` / `connection` / `upstream`) → `mapUpstreamError`.
- Переменные: `AI_PROVIDER` (`anthropic` | `openai`), `AI_MODEL`, `AI_BASE_URL`, `AI_EXTRA_HEADERS`, секрет `AI_API_KEY` (для Anthropic — по-прежнему `ANTHROPIC_API_KEY`); переопределения для повара `CHEF_PROVIDER` / `CHEF_MODEL` / `CHEF_BASE_URL` / `CHEF_API_KEY` / `CHEF_EXTRA_HEADERS`. Старая `MODEL` работает как `AI_MODEL`. Нет ключа для выбранного провайдера → `503 provider_not_configured`.
- `/health` → `providers: {chat: {id, model}, chef: {id, model}}` без ключей и baseUrl. Промпты по смыслу не менялись; для JSON-режима без `json_schema` описание схемы генерируется из zod автоматически.
- Тесты: `providers.test.ts` (выбор по переменным, `CHEF_*`, `MODEL`, отсутствующий ключ), `openaiCompatible.test.ts` на моке `fetch` (json_schema, откат на json_object, повтор → `bad_output`, маппинг ошибок, data-URL, доп. заголовки), `/health` без секретов.
- Android: без изменений (`aiModel` в `brands/*.properties` — только для debug-режима «свой ключ»).

### Документы
- README («Любая нейросеть», технологии), ARCHITECTURE (слой `providers/`, переменные, схема «приложение → прокси → провайдер по выбору»), WHITE_LABEL (шаг 4: выбор модели одной переменной), прайс (вопрос «а если захотим другую нейросеть?», цифры себестоимости — для Claude как пример), возражение 9 «мы хотим GPT / Gemini / местную модель», конкуренты (завязка на одного вендора снята), лендинг (FAQ «Какая нейросеть внутри?»), PRIVACY_POLICY RU/KK (провайдер модели ИИ, выбранный Клубом — `{{AI_PROVIDER_NAME}}`), `proxy/README.md` (таблица провайдеров, «Повар на другой модели»), комментарии в `brands/*.properties` и `wrangler.toml`.

## 1.1.0 — AI-повар (2026-10-03)

### Продукт
- **План питания** на 3/5/7 дней под цели профиля (ккал/БЖУ): кухня (казахская / домашняя / любая), халяль, бюджет, исключения и аллергии, 3–5 приёмов в день, «готовлю заранее на 2 дня». Приём пищи — ингредиенты с граммами, КБЖУ, 2–4 шага, время готовки; «Добавить в дневник» одним тапом; сравнение «цель · план»; «Пересоставить», «Удалить план». Язык плана = язык интерфейса (RU/KK).
- **Список покупок** из плана: группы по отделам магазина, количества (г/кг/шт/л), объединённые дубликаты, чекбоксы «куплено» с прогрессом, «Поделиться» текстом (WhatsApp и любое приложение), «Снять все отметки». **Напоминание «пора за покупками»**: день недели + время, локальное уведомление с переходом в список; молчит, если список пуст.
- **Фото еды → КБЖУ**: системная камера (без разрешения CAMERA) или галерея → уменьшение до 1024 px на устройстве → прокси → Claude (vision) → блюда с граммами, КБЖУ, уверенностью и подсказкой; граммы правятся с пересчётом, «Добавить в дневник» по записи на блюдо с выбором приёма пищи; «не еда» — понятное сообщение. Одноразовая подсказка о передаче фото в AI-сервис клуба; файл фото удаляется после анализа.
- Карточка «AI-повар» на экране питания (фото · план · покупки, бейдж «осталось купить»); значки 📷/🍽 у записей дневника из фото и плана.
- Демо-режим без прокси и интернета: готовый 3-дневный план с казахской кухней и фиксированный разбор фото с пометкой «демо-оценка»; «Загрузить 3 недели» добавляет демо-план и список покупок с отмеченными позициями; «Очистить всё» удаляет планы и список.
- Текст согласия (RU/KK) дополнен передачей фото еды.

### Инженерия
- Прокси: `POST /v1/meal-plan` и `POST /v1/food-photo` со структурированным выводом (`messages.parse` + zod-схемы), серверная проверка и пересчёт списка покупок, отдельные дневные лимиты на устройство (`DAILY_LIMIT_PLANS_PER_DEVICE` = 3, `DAILY_LIMIT_PHOTOS_PER_DEVICE` = 20), тело ≤ 2 МБ, `422 refused` при отказе модели, `/health` → `features`. Unit-тесты агрегации (`proxy/test`, `npm test`).
- Android: пакет `ai/chef` (`AiChefClient`: Proxy/Demo, `AiChefSelector` без режима прямого ключа), Room v4 (`meal_plans`, `shopping_items`, `nutrition_entries.source`), `MealPlanRepository`, `ShoppingReminderWorker` + чистая `nextTrigger`, переход из уведомления по extra `nav_route`, FileProvider `cache/photos`, `androidx.exifinterface`.
- Тесты: парсинг `MealPlan`/`FoodAnalysis` (с неизвестными полями), пересчёт граммов → КБЖУ, демо-повар RU/KK, границы `nextTrigger`.

### Документы
- README (таблица и раздел «AI-повар», скриншоты 07/08), ARCHITECTURE (пакет `ai/chef`, Room v4, эндпоинты прокси), PRIVACY_POLICY RU/KK (фото еды, планы, покупки), RELEASE (Data Safety: фото), прайс (AI-повар в «Клуб»/«Эксклюзив», лимиты, себестоимость), сценарий демо (2 новых вау-момента), Instagram (2 поста), лендинг (карточка, скриншоты, FAQ), КП и one-pager, WHITE_LABEL.

## 1.0.0 — white-label релиз для продажи (2026-09-28)

### Продукт
- White-label: `brands/*.properties` → отдельная сборка на клуб (имя, id, цвета, логотип, контакты, AI-прокси); проверка контраста при сборке; второй пример бренда.
- Онбординг: язык RU/KK, профиль, цель, уровень, дни, ограничения по здоровью, расчёт КБЖУ/воды (Mifflin-St Jeor), подбор программы, согласие и медицинский дисклеймер.
- 3 программы × 12 недель × 3 фазы с гибким графиком («следующая тренировка», старт в любой день), словесные подсказки по весу, автозамена упражнений при ограничениях, «Отметить активность».
- Тренировка: ввод веса/повторов с подстановкой «прошлый раз», отмена сета, таймер отдыха (bottom sheet, ±15 с, вибрация и сигнал), замена упражнения, честная длительность; итог с объёмом, рекордами, стриком, бейджем и кнопкой «Поделиться в Stories».
- AI-тренер: прокси-клиент (ключ у клуба, лимиты), демо-режим офлайн (RU/KK), режим разработчика в debug; универсальный промпт без персональных идентификаторов, безопасность, мягкая рекомендация услуг клуба; чат с кнопкой «Спросить тренера» в WhatsApp.
- Вкладка «Клуб»: контакты, 2GIS, WhatsApp/Instagram, часы, запись к тренеру, акции, расписание групповых, тренеры, услуги; контент из `club.json`/Google Sheets с кэшем и локальным уведомлением о новой акции; баннер акции на главной.
- Карта участника (код + QR), карточки для Instagram Stories 1080×1920 с логотипом клуба и промокодом, прогресс с графиком веса и бейджами, демо-данные на 3 недели, база продуктов с казахской кухней.
- Локализация RU/KK всего интерфейса, переключатель языка.

### Инженерия
- Gradle wrapper, Room v3, HiltWorkerFactory, уведомления с иконкой бренда и переходом в приложение, FileProvider, splash, адаптивная иконка.
- Логирование тела HTTP убрано, ключ вынесен из БД, R8-правила для kotlinx.serialization.
- Unit-тесты (калькулятор целей, программы, стрики, бейджи, санитайзер чата, демо-AI, JSON клуба, QR), GitHub Actions (тесты + сборка всех брендов + артефакты), подпись релиза через переменные окружения.
- Cloudflare Worker `proxy/` на `@anthropic-ai/sdk` с лимитами на устройство и на клуб.

### Документы
- README, ARCHITECTURE, WHITE_LABEL, RELEASE, CLUB_CONTENT, PRIVACY_POLICY (RU/KK), комплект продаж `docs/sales/` (план на 90 дней, целевые клубы, прайс, шаблоны сообщений и писем, сценарий демо, видео, Instagram-стратегия, комплект запуска в клубе, конкуренты, юридический пакет, лендинг, ROI-калькулятор, КП).
