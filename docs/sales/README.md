# Комплект продаж (sales kit)

Для разработчика-одиночки, который сам продаёт white-label фитнес-приложение с AI-тренером владельцам клубов Казахстана. Все цены — в `02_ПРАЙС_И_ПАКЕТЫ.md`, остальные документы на него ссылаются. Факты рынка — с источниками из исследования (сентябрь 2026); где факта нет — пометка «(проверить)».

## С чего начать в первый день (5 шагов)

1. **Прочитать `02_ПРАЙС_И_ПАКЕТЫ.md` целиком** и выучить три цифры и одно правило: 1 490 000 / 2 990 000 / 7 900 000 ₸; пилот 450 000 ₸ с полным зачётом; бесплатных пилотов и скидок «просто так» нет.
2. **Собрать демо-телефон** по `docs/WHITE_LABEL.md`: бренд `demo` + `atlantfit`, «Загрузить 3 недели» (Настройки → Демо-данные), «Демо-режим AI (офлайн)»; прогнать `04_СЦЕНАРИЙ_ДЕМО.md` три раза в авиарежиме.
3. **Заполнить 30 строк базы** по `01_ЦЕЛЕВЫЕ_КЛИЕНТЫ.md` §2–3 (начать с приоритета A своего города) в CRM-таблицу из `00_ПЛАН_ПРОДАЖИ_90_ДНЕЙ.md` §7.1.
4. **Отправить 10 первых касаний** шаблоном №1 или №2 из `03_ШАБЛОНЫ_ПИСЕМ_И_СООБЩЕНИЙ.md` — будни, 11:00–15:00, одно наблюдение + один вопрос, без ссылок.
5. **Заменить контакты в `landing/index.html` и опубликовать** по `landing/README.md`; ссылку — в био Instagram (`06_INSTAGRAM_СТРАТЕГИЯ.md` §1) и в подпись WhatsApp. Параллельно — открыть ИП на упрощёнке с ОКЭД 62011 (`10_ЮРИДИЧЕСКИЙ_ПАКЕТ.md` §7) и отдать юристу договор из §2 на проверку.

Через неделю: первое видео по `05_ВИДЕО_ДЕМО_РАСКАДРОВКА.md`, первые 3 поста по `06_…`, разбор воронки по `00_…` §8.
