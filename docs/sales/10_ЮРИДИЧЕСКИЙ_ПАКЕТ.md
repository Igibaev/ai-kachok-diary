Разделение важно для бухгалтерии клуба и для того, чтобы при остановке подписки лицензия на уже переданную версию **сохранялась** (клуб не теряет приложение).

Язык договора: русский; по требованию клуба — двуязычный RU/KK (Закон «О языках» — проверить обязательность для сделок между резидентами).
