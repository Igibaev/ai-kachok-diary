# Лендинг: публикация за 5 минут и замена контактов

`index.html` — один файл: встроенный CSS, без внешних скриптов и шрифтов, работает офлайн (открыть двойным кликом). Картинки берутся из `docs/img/` по относительному пути `../../img/…`, калькулятор и КП — из `docs/sales/` (`../roi_calculator.html`, `../kp_onepager.html`). Поэтому **не переносить файл отдельно** — публиковать вместе с папкой `docs/`.

## 1. Заменить контакты (2 минуты)

Открыть `index.html` в любом редакторе и заменить:

| Что искать | На что менять | Где встречается |
|---|---|---|
| `7XXXXXXXXXX` | ваш номер WhatsApp цифрами с кодом страны, например `77011234567` | 4 ссылки `https://wa.me/…` (шапка, hero, финальный блок, футер) |
| `+7 XXX XXX XX XX` | номер в читаемом виде | футер |
| `hello@example.kz` | ваш e-mail | футер |
| `your_account` | ваш Instagram без `@` | футер |
| `{{ИМЯ ПРОДАВЦА}}`, `{{ИП / ТОО}}`, `{{БИН}}`, `{{ГОРОД}}` | реквизиты | футер |

Текст `?text=ДЕМО` в ссылках WhatsApp — предзаполненное сообщение; можно заменить на `?text=Здравствуйте,%20хочу%20демо` (пробелы — `%20`).

Цены в таблице — из `../02_ПРАЙС_И_ПАКЕТЫ.md`. Если меняете прайс — менять и здесь (раздел «Пакеты и цены» и FAQ «Дорого»/«А iOS?»).

## 2. Опубликовать на GitHub Pages (3 минуты)

1. Репозиторий на GitHub (публичный или приватный с GitHub Pro).
2. **Settings → Pages → Build and deployment → Source: «Deploy from a branch»**, Branch: `main`, Folder: **`/docs`** → Save.
3. Через 1–2 минуты страница доступна по адресу:
   `https://<ваш_логин>.github.io/<репозиторий>/sales/landing/`
   Калькулятор: `…/sales/roi_calculator.html`, КП: `…/sales/kp_onepager.html`.
4. Ссылку — в био Instagram и в подпись WhatsApp Business.

Если репозиторий приватный и Pro нет — создать отдельный публичный репозиторий `landing` и скопировать в него **всю папку `docs/`** (структура путей должна сохраниться), Folder: `/docs`. Либо скопировать в корень нового репозитория `index.html`, `roi_calculator.html`, `kp_onepager.html`, папку `img/` и поправить пути в `index.html` (`../../img/` → `img/`, `../roi_calculator.html` → `roi_calculator.html`).

Свой домен (`app.{{ваш-домен}}.kz`): Settings → Pages → Custom domain → у регистратора CNAME на `<логин>.github.io`. Не обязательно для старта.

## 3. Проверить

- [ ] Открыть страницу с телефона: нет горизонтальной прокрутки, таблица цен листается пальцем.
- [ ] Все 4 кнопки WhatsApp открывают чат с вашим номером.
- [ ] Переключатель RU/KK меняет тексты hero и кнопок.
- [ ] Картинки загрузились (если нет — проверить, что `docs/img/*.png` в репозитории и пути не менялись).
- [ ] Ссылка «Открыть калькулятор» ведёт на `roi_calculator.html`.
- [ ] Политика конфиденциальности в футере — ссылка на шаблон; для клуба-клиента публикуется отдельная политика с его реквизитами (`docs/PRIVACY_POLICY_ru.md`, `_kk.md`).

## 4. Что менять под конкретного клиента (по желанию)

Копия `index.html` → `index_{{club}}.html`: заменить скриншоты на сборку с брендом клуба (те же имена файлов в отдельной папке `img_{{club}}/`), в hero добавить «для {{Клуб}}», цвет акцента `--accent` в `:root` — на фирменный цвет клуба (проверить контраст на тёмном фоне). Отправлять ссылку после демо вместе с КП.
