# Видео-демо 60–90 секунд: раскадровка

Назначение: касание №2 в WhatsApp/DM (после первого ответа), вложение к КП, закреп в Instagram продавца, Reels. Вертикаль 9:16 (1080×1920), с субтитрами — 80 % смотрят без звука. Две версии: **60 с** (WhatsApp, без диктора, только титры) и **90 с** (Instagram/КП, с диктором). Записывается **на сборке с брендом конкретного клуба** — под каждого A-клиента своё видео (30 минут работы после первой сборки), для Instagram — на бренде `demo`/`atlantfit`.

Хук — в первые 2 секунды: логотип клуба на иконке, ещё до любого текста ([Contentdrips](https://contentdrips.com/blog/2026/06/instagram-reels-vs-carousels-2026-guide/): хук 1,5–3 с, 30–90 с для обучающих Reels).

## Как снять

### Запись экрана (Android)

1. Телефон с брендом клуба, «Загрузить демо-данные (3 недели)», «Не беспокоить», яркость 100 %, уведомления выключены, батарея ≥ 50 % (индикатор не должен краснеть в кадре).
2. Встроенная запись экрана (шторка → «Запись экрана», включить «Показывать касания» в настройках разработчика — палец на экране помогает зрителю). Разрешение 1080p, 60 fps если есть, звук системы выключен.
3. Записать **каждый кадр отдельным дублем** по 10–20 с — монтаж проще, чем один длинный прогон. Между действиями пауза 1 с — под титры.
4. Кадр 11 (Google-таблица): записать экран ноутбука (Win + G / QuickTime) или второй телефон с открытой таблицей; телефон с приложением снять на второй телефон «через плечо» — либо split-screen в CapCut: таблица сверху, приложение снизу.
5. Кадр 1: снять реальный домашний экран — иконка клуба рядом с WhatsApp и Instagram; это самый важный кадр.
6. Чат: вопросы вводить заранее подготовленной подсказкой или вставкой из буфера — набор текста на видео ускорить ×3 при монтаже.

### Монтаж (CapCut, бесплатно, телефон или ПК)

1. Новый проект 9:16. Импорт дублей по порядку таблицы.
2. Обрезать паузы, ускорение ×2–3 на наборе текста и ожидании ответа AI (ответ появляется — вернуть ×1).
3. Титры: шаблон «крупный текст» вверху экрана, шрифт без засечек (Inter/Montserrat), белый с чёрной подложкой 70 %, размер — читается на телефоне при масштабе превью. Один титр = один кадр. Титры на русском; для казахоязычных клиентов (Шымкент, Актобе) продублировать титры на KK во второй версии — 15 минут работы.
4. Диктор (версия 90 с): записать голос на телефон в тихой комнате одним дублем по тексту таблицы, наложить, подогнать кадры под голос, а не наоборот. Или CapCut «Текст → Озвучка» (проверить качество русского голоса, казахского в CapCut может не быть — проверить).
5. Музыка: из библиотеки CapCut без авторских прав, громкость −20 дБ под диктором. Для Instagram — трендовый звук из библиотеки Instagram при загрузке, музыка в файле — тишина.
6. Автосубтитры (CapCut «Автоподписи») для дикторской версии — проверить орфографию, имена тренеров и казахские слова.
7. Экспорт: 1080p, 30 fps, битрейт «рекомендуемый», H.264. Файл для WhatsApp — ≤ 16 МБ (иначе сожмётся), для Instagram — до 4 ГБ. Для WhatsApp экспортировать 720p, если 1080p превышает лимит.
8. Первые 3 секунды: без заставки, без «Привет, меня зовут». Сразу иконка.

Время на первое видео — 2–3 часа; на пересборку под нового клиента (заменить кадры 1, 2, 7, 9, 12) — 30–40 минут.

### Хранение и отправка

- Файл `demo_{{club}}_60.mp4` и `demo_{{club}}_90.mp4` в папке клиента на Google Drive; в WhatsApp отправлять **файлом** (скрепка → Документ), а не как видео — так не сжимается.
- В Instagram: Reels + закреп в профиле; ссылка на Reels — в сообщение №5 (`03_ШАБЛОНЫ_ПИСЕМ_И_СООБЩЕНИЙ.md`).
