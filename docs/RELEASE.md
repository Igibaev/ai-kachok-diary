# Релиз и публикация для клиента

## 1. Подпись

Каждому клиенту — отдельный keystore (он же понадобится для всех будущих обновлений; потеря = невозможность обновить приложение).

```bash
keytool -genkeypair -v -keystore ironclub-release.jks -alias ironclub -keyalg RSA -keysize 2048 -validity 10000
```

Храните `.jks` и пароли в менеджере паролей, копию — у клиента (по договору). В репозиторий не коммитить (`*.jks` в `.gitignore`).

Сборка с подписью:

```bash
export KEYSTORE_PATH=/secure/ironclub-release.jks
export KEYSTORE_PASSWORD=… KEY_ALIAS=ironclub KEY_PASSWORD=…
./gradlew :app:bundleIronclubRelease -PversionCode=3     # .aab для Google Play
./gradlew :app:assembleIronclubRelease -PversionCode=3   # .apk для прямой установки / AppGallery
```

Без переменных окружения release подписывается debug-ключом — удобно для демо, но такой APK **нельзя** загружать в магазин.

`versionCode` — целое число, увеличивается на 1 с каждым релизом (передаётся `-PversionCode=N`); `versionName` — в `brands/<клиент>.properties`.

## 2. Google Play (рекомендуется публиковать под аккаунтом клуба)

1. Клуб создаёт аккаунт разработчика Google Play (единоразово $25; для организации нужна верификация: юридическое лицо, адрес, сайт/e-mail на домене; занимает от нескольких дней до 2–3 недель). Вас добавляют как пользователя с правом релизов.
2. Создать приложение → загрузить `.aab` во **Внутреннее тестирование** → проверить на 2–3 телефонах.
3. Заполнить карточку: название (до 30 симв.), краткое описание (80), полное (4000), иконка 512×512, feature graphic 1024×500, 4–8 скриншотов телефона (сделайте с демо-данными; включите план питания и «Фото еды → КБЖУ» — заметные функции для карточки).
4. **Политика конфиденциальности** — обязательна: опубликуйте `docs/PRIVACY_POLICY_ru.md` (и kk) на сайте клуба или GitHub Pages и укажите ссылку.
5. **Безопасность данных (Data Safety)**: данные хранятся локально (`allowBackup=false` — в облачный бэкап не уходят); при использовании AI-чата и AI-повара на прокси клуба и далее процессору Anthropic отправляются текст диалога, обезличенный контекст (пол, возраст, рост, вес, цели, ограничения по здоровью), предпочтения по еде для плана питания и — только по действию пользователя — уменьшенное фото еды для оценки КБЖУ, плюс случайный идентификатор устройства для лимитов. Фото не хранится ни на прокси, ни в приложении (файл удаляется после анализа); планы питания и список покупок — только на устройстве. Укажите:
   - «Здоровье и фитнес» (Health info) — собирается; передаётся поставщику услуг (провайдер модели ИИ, выбранный клубом, по умолчанию Anthropic, как процессор), не для рекламы; шифрование в транзите — да (только HTTPS);
   - «Сообщения» (Messages) — собирается при использовании чата, передаётся так же;
   - «Фото и видео» (Photos and videos → Photos) — собирается при использовании «Фото еды → КБЖУ»: снимок передаётся поставщику услуг (прокси клуба → Anthropic как процессор) только для анализа в момент запроса и не хранится (обработка на сервере, без сохранения); не для рекламы; шифрование в транзите — да; функция необязательная, пользователь решает сам. Формально это «временная обработка» (ephemeral processing), которую Play разрешает не декларировать, но у приложения есть камера/галерея — задекларировать безопаснее;
   - «Идентификаторы устройства или другие» (Device or other IDs) — собирается (случайный UUID приложения, не рекламный ID), передаётся на прокси для лимитов;
   - удаление данных: пользователь может удалить дневник, чат, планы питания и список покупок («Настройки → Демо-данные → Очистить всё») и все данные — удалением приложения; аккаунтов нет.
   Ссылка на политику конфиденциальности должна быть и в листинге, и в приложении (`privacyPolicyUrl` в `brands/<клиент>.properties`).
6. Рейтинг контента → анкета IARC (нет насилия/азартных игр) → 3+.
7. Целевая аудитория: 18+ (тренировки и питание).
8. Производственный релиз. Первое ревью — 1–7 дней.

## 3. Huawei AppGallery (в Казахстане много Huawei/Honor без Google Play)

Аккаунт разработчика Huawei бесплатный. Загружается тот же подписанный `.apk`/`.aab`. Уведомления в этом приложении локальные (WorkManager), Google-сервисы не нужны — на Huawei всё работает.

## 4. Обновления

1. Правки → `versionName` в `brands/<клиент>.properties`, `-PversionCode=N+1`.
2. Собрать `.aab`, загрузить в Play Console → Production → «Создать выпуск».
3. Обновление AI-прокси (`proxy/`) клиенту не требует релиза приложения.

## 5. Чек-лист перед передачей клиенту

- [ ] Бренд-файл, логотип, `club.json` проверены владельцем клуба
- [ ] AI-прокси развёрнут, `curl …/health` отвечает (`features: chat, meal-plan, food-photo`), лимиты чата, планов и фото выставлены по пакету клуба
- [ ] Release-сборка установлена на телефон клуба, пройден онбординг, работает чат, AI-повар (план и фото через прокси, не демо-заглушки), шаринг, звонок/WhatsApp
- [ ] Политика конфиденциальности опубликована, ссылка в Play Console
- [ ] Keystore и пароли переданы клиенту в закрытом виде, копия у вас
- [ ] Подписан акт передачи (см. `docs/sales/`)
